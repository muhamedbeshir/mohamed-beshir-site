# موقع wahba — نسخة محلية كاملة

## إزاي تشغّله

دوس دبل كليك على:

```
start-server.bat
```

هيبدأ السيرفر ويفتح المتصفح على <http://localhost:4743>

أو من التيرمنال:

```bash
node server.mjs
```

لتغيير البورت: `set PORT=5000 && node server.mjs`

> مهم: الموقع لازم يفتح من خلال السيرفر (http://localhost:4743) ومش بالدبل كليك على `index.html`،
> لأن Next.js بيحمّل ملفاته من مسارات جذرية زي `/_next/...`.

## اللي كان بايظ واتصلّح

1. **النسخة كانت ناقصة** — HTTrack نزّل 32 ملف بس من أصل 110+، فالصور والفيديوهات والخطوط
   وأكواد الجافاسكريبت كانت ضايعة، والصفحة كانت بتظهر ناقصة أو ثابتة بدون أي تفاعل.
2. **ملف جافاسكريبت أساسي كان مفقود** — `0c0hxoamwjsbw.js` (112 كيلوبايت)، وبدونه الـ hydration
   كله كان بيقع.
3. **صور الأصول الغائبة** — مجلدات `brand/letters/*`، `brand/floating/*`، `brand/folders/*`،
   صور المشروع في `projects/pola-samy/*`، والأصوات في `audio/*` (كانت كلها 404).
4. **روابط مطلقة للإنترنت** — الصور كانت بتشاور على `https://portfolio2027-ten.vercel.app/...`
   بدل ما تكون محلية، فكان الموقع بيفضل يعتمد على النت.
5. **روابط `/_next/image`** — الـ image optimizer بتاع Next كان بيدّي 404، فاتعمل بديل في السيرفر
   بيرجّع الصورة الأصلية مباشرة.
6. **الفافيكون** — `/icon?hash` اتحوّل لـ `icon.png` محلي.
7. **التنقل بين الصفحات (RSC)** — سيرفر Next محتاج يرجّع الـ RSC payload مع كل تنقل،
   فالسيرفر المحلي بقى يخدم `?_rsc=` من ملفات `index.rsc` اللي اتنزّلت.

## التحقق

اتعمل فحص في متصفح حقيقي (Chrome headless) على الأربع صفحات:

- 0 أخطاء في الكونسول
- 0 طلبات شبكة فاشلة (404)
- 0 صور مكسورة (46 صورة في الرئيسية)
- الخطوط العربية (Thmanyah) والحركات والتفاعلات شغالة

## الملفات

## طبقة الثيم (beshir-theme.*)

- `beshir-theme.css` + `beshir-theme.js` ملفين بس (البوب‑أب اتدمج جواهم). كل الـ selectors والـ events اللي الكود معتمد عليها متوثّقة في أول `beshir-theme.js`.
- شادر الـ WebGL اتشال (كان مخفي بالـ CSS). نسخته في `_backup_bone/bt-shader-mount.js.txt`.
- الـ halo بيوقف الـ requestAnimationFrame لما الماوس يسكت أو التاب يتخفّى، والـ grain والـ halo بيتقفلوا مع `prefers-reduced-motion`.
- صور `brand/` اتضغطت (8.9MB → 3.4MB)، والأصول الأصلية في `_backup_images/`.
- نسخ ما قبل التنظيف: `_backup_bone/*.before-cleanup.*`.
